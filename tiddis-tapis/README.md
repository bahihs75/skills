# tiddis-tapis

`tiddis-tapis` is a complete luxury-rug commerce and Firebase operations skill. It is suitable for visually rich catalogues where customers need credible product detail, search/filter discovery and a trusted order or quote route, while owners need a secure custom administration system.

## Coverage

The guide covers route architecture, Firestore collections, media storage, rules/functions, product variants, filtering, editorial UI, owner operations, analytics, testing and deployment safeguards. It includes no copied code, media, customer information or brand identity.

## Apply it

Read `SKILL.md` with [`../STANDARDS.md`](../STANDARDS.md). Use `make-ur-kdb` when a user also asks for platform selection and a full all-in-one storefront/owner-control build.

## Non-negotiable rule

Price, stock, order/quote state and private content operations must be trusted server/function work. Hiding an admin page or relying only on a client condition is not authorization.
