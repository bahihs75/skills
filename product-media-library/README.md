# product-media-library

This package turns a raw product-photo collection into a governed commerce-media system. It is useful before a catalogue exists, during a store migration, or when a team needs to stop treating image files as untracked page content.

## Scope

The skill defines inventory, checksums, source/derivative/link/review records, object storage, rights and approval gates, factual alt text, crop/quality checks, responsive delivery, analytics and test cases.

## Use with

Read `SKILL.md` plus [`../STANDARDS.md`](../STANDARDS.md). Combine it with `make-ur-kdb`, `carpet`, `tiddis-tapis` or another commerce skill when these assets will feed product or editorial surfaces.

## Honesty rule

Images are evidence of appearance, not permission to invent product claims or availability. Preserve source provenance and keep uncertain assets out of production until reviewed.
