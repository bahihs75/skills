# Afak Carpet Reference Skill

Create an original, bilingual carpet showroom that begins with the customer’s project context—mosque, hotel, school or large space—then guides them to relevant materials and a focused quote request.

## Experience architecture

Use editable hero storytelling, sector discovery, product cards and details, colors/material/specifications, project gallery, factual trust content, contact/WhatsApp actions, and Arabic/English language switching with correct RTL/LTR direction. Maintain reading order, spacing and icon direction separately for each language.

## Content and operations

Give authenticated owners control over brand settings, hero slides, categories, products, projects, factual statistics/certifications, media, section visibility and quote-request statuses. Use compact list/detail editing for long catalogues.

## Quote and security contract

Collect only name, phone, sector, wilaya, commune, project message and optional product snapshot. Validate and normalize client input, give requests a server-controlled initial state, keep orders unreadable publicly, restrict owner updates, escape managed text and allow only safe HTTP(S) links.

## Firebase deployment

Use Firestore for content and requests, Firebase Authentication for owners, deployed rules as the final authority, and approved object/media storage. Test anonymous denial, authenticated updates, Arabic/English layouts, mobile drawer behavior, quote status changes and media fallbacks.
