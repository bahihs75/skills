# afak-carpet-skill

This package creates original bilingual Arabic/English carpet and project-quotation systems for Algerian suppliers. It is aimed at a sector-led showroom rather than a generic product grid.

## Included detail

The skill covers RTL/LTR design, localized content and product data, sectors, specifications, approved projects, 58-wilaya/commune selection, private quote workflow, Firebase CMS/rules/storage, owner operations, analytics and testing.

## Usage

Read `SKILL.md` followed by [`../STANDARDS.md`](../STANDARDS.md). Apply `make-ur-kdb` when the project needs broader storefront, cart, delivery, owner-control and deployment selection in addition to quotation.

## Source and content integrity

Only publish authorized project/media information and verified product facts. Never generate client names, certifications, testimonials, completion statistics or quote histories.
