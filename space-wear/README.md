# space-wear

`space-wear` is a full commerce-and-operations skill for fashion brands that need an industrial editorial public identity and a deeply capable custom administration room. It covers customer shopping, delivery, product/media/content operations, governance, analytics and recoverability.

## What makes it distinct

The package requires a deliberate Swiss Industrial Print or Tactical Telemetry visual mode, not a generic ecommerce template. It also specifies the entire owner-control matrix: access, overview, hero/content, catalogue, collections, delivery, orders, media, legal/consent, reports, activity and backup/restore.

## Recommended use

Read `SKILL.md` and [`../STANDARDS.md`](../STANDARDS.md). Use `make-ur-kdb` for a platform-selection intake and full premium commerce plan, then apply this skill when industrial-editorial brand language and comprehensive operational governance are central.

## Integrity boundary

Use only verified product, delivery and operational data. Do not imitate another brand’s identity or fabricate reviews, sales, inventory, customer data or analytics.
