# Space Wear Reference Skill

Build an original fashion-commerce system where public brand expression and owner operations are equally intentional. Use an industrial editorial language—precise grids, strong type hierarchy, disciplined color and utility-led controls—without copying the reference identity.

## Public storefront

Implement editorial hero, category-led discovery, search/filter behavior, product/variant/size states, delivery clarity, cart/checkout, account/order views where required, responsive navigation and policy/contact surfaces. Keep product availability, pricing and delivery truthful.

## Owner control-room checklist

Implement access control, overview KPIs, hero studio, storefront copy, product catalogue, collections, catalogue behavior toggles, 58-wilaya delivery, order operations, media library, identity/legal settings, consent/marketing controls, reports, activity log and guarded JSON backup/recovery.

## Runtime parity

Document which duties run in a local server, Cloudflare Worker, Firebase Functions or Neon-backed service. Keep the domain model and authorization semantics consistent across environments. Verify migrations, startup configuration, storage paths and secrets for each selected runtime.

## Operational quality

Add health checks, data-quality checks, regression tests for admin/public separation, delivery picker contrast, product-size visibility, media/upload safety and low-stock reporting. Keep admin discovery out of public navigation.
