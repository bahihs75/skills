# Carpet Reference Skill

Turn a carpet, interiors, materials, or portfolio brief into a polished original public experience. Establish a deliberate visual system, separate public routes from server contracts, and keep animation secondary to readability and conversion.

## Workflow

1. Define tokens for background, surface, ink, accents, borders, typography and motion before composing sections.
2. Organize discovery around an editorial hero, collection narrative, product/material rail, selected work, specifications, enquiry or shopping action, and contact.
3. Make every image treatment intentional: crop, alt text, loading, mobile focal point and fallback state.
4. Use typed schemas for form payloads and server actions; keep visitor pages independent of internal operations.
5. Verify reduced motion, visible focus, responsive image ratios, contrast and mobile navigation.

## Design rules

Prefer asymmetric editorial composition, generous whitespace, clear type scale, tactile material photography and short factual copy. Avoid generic dashboard cards on public pages, excessive gradients, decorative emojis, copied layouts, or unverified claims.

## Deliverables

Provide an original responsive design system, route map, component boundaries, form validation plan, accessibility checklist and production-build verification. If commerce is requested, combine with `make-ur-kdb`.
