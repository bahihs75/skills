# carpet

This package is a complete guide for original premium carpet, interior and material-led storefronts. It focuses on editorial composition, structured product/specification data, authentic media treatment, clear quote or commerce conversion, and accessibility.

## Trigger

Use this package when a user asks for a carpet catalogue, interior-material website, high-end portfolio, project gallery, product discovery experience, sample/enquiry flow, or a store that must feel considered rather than template-based.

## What it delivers

It defines the product, specification, collection, project, media and enquiry records; the customer route map; image and responsive rules; server-side quote/commerce boundaries; API/privacy controls; analytics; and release tests. Read `SKILL.md` together with [`../STANDARDS.md`](../STANDARDS.md).

## Originality rule

The pattern is material-led and editorial, not a license to reuse any reference’s design, copy, media, price, project, customer identity or brand assets.
