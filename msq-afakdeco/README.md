# msq-afakdeco

This package builds original Arabic-first carpet quotation showrooms for mosques and institutional projects. It is designed for a project-sales journey: sector discovery, specifications, location-aware quote capture, and protected content/quote operations.

## Key capabilities

The skill defines bilingual and RTL requirements, sector and product-family data structures, Firebase security boundaries, a quote state machine, media governance, analytics, and test coverage. It distinguishes estimate/price-band presentation from final project quotation.

## How to apply it

Read `SKILL.md` first, then apply the universal requirements in [`../STANDARDS.md`](../STANDARDS.md). Pair it with `make-ur-kdb` only when a full commerce and owner-control system is also required.

## Integrity rule

Use only verified material/product information and authorized imagery. Do not fabricate certifications, portfolio work, client references or quote outcomes.
