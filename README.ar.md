# مكتبة المهارات

هذا المستودع هو مكتبة منظّمة من **حزم المهارات الموجّهة للوكلاء**. يحتوي على مهارة قابلة لإعادة الاستخدام لبناء متجر ولوحة مالك باسم `make-ur-kdb`، وعلى مهارة مرجعية أصلية لكل مستودع GitHub مرتبط بهذه الجلسة. جرى تحليل المستودعات المصدرية كمراجع **للقراءة فقط**، ولم يُعدّل إلا مستودع `skills`.

## طريقة الاستخدام

يحتوي كل مجلد على ملف `SKILL.md` يضم بيانات تشغيل YAML وتعليمات عملية مركّزة. ابدأ بـ `make-ur-kdb` عند الحاجة إلى موقع تجارة راقٍ كامل ولوحة مالك مخصّصة ومخفية عن العملاء. تطلب المهارة فقط اسم العلامة ولوحة الألوان والخط المفضّل، أو تعتمد خط KDB الافتراضي، والعملة ومنصة الاستضافة ومنصة البيانات.

المهارات الخاصة بالمستودعات هي أدلة مركّزة. يمكن استعمالها منفردة لمجالها أو مع `make-ur-kdb` في مشروع أكبر. هي تشرح الأنماط والفحوصات والمخططات وسير العمل وحدود الجودة، ولا تنسخ الكود أو بيانات العملاء أو الصور أو الأسرار أو الهوية التجارية أو المحتوى الخاص بالمستودعات المرجعية.

## معيار الجودة

جميع الحزم مهيأة ومتحقَّق منها بأداة فحص حزم المهارات. تستخدم المجلدات معرّفات صغيرة مفصولة بشرطات حتى تبقى بيانات التشغيل قابلة للنقل، حتى عندما يحتوي اسم المستودع المصدر على أحرف كبيرة أو علامات خاصة.

> تتطلب المهارات تنفيذاً أصلياً. لا يجوز نسخ كود المرجع أو بيانات العملاء الحية أو بيانات الدخول أو حقوق الصور أو الهوية التجارية. كما تحظر المهارات اختلاق التقييمات أو الشهادات أو أرقام المبيعات أو المخزون أو الطلبات.

راجِع [`LIBRARY_DESIGN.md`](./LIBRARY_DESIGN.md) لبنية المكتبة وعقد مدخلات `make-ur-kdb`، وراجِع [`AUDIT.md`](./AUDIT.md) لملخص تحليل المراجع للقراءة فقط.
