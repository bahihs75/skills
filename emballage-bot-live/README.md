# emballage-bot-live

This package is for Telegram-to-product-page publishing workflows. It enables authorized operators to create a structured product draft in chat, validate media and details, publish through a trusted backend, and receive orders through protected server routes.

## What the skill enforces

It defines roles, durable conversation state, product/media/publish-job records, safe templating, server-only deployment credentials, idempotency, order validation, audit events, responsive product UI, analytics and recovery tests.

## Use it responsibly

Read `SKILL.md` and [`../STANDARDS.md`](../STANDARDS.md). The bot may collect data, but it must not become the security boundary for publishing, payments, customer data or deployment secrets.
